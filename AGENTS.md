# Instructions for agents

This repository holds the FPSOT style specification.
It covers design tokens, component states, errors, loading and empty states, destructive actions, and themes (the PatternFly default, Québec and Canada).

- The normative text is in `spec/en/` and `spec/fr/`. Every rule has an ID such as `STY-001`.
- Follow `skill/SKILL.md` when you work on screens, tokens or themes of an FPSOT product. The spec text wins on any difference.
- Never restate or change an accessibility value here. Point to the FPSOT accessibility specification instead.
- Every page exists in English and in French, with the same file name and the same IDs.
- Terms and abbreviations come from the term base of `fpsot-spec-writing`. Add a missing term there first.
- Do not copy text from outside standards or design systems. Summarize them in your own words and cite the exact version.
- Commits follow Conventional Commits and are signed. Pull requests are squash-merged.
